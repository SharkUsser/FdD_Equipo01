# Producto 1

### Nombre del Producto

### **Hydrawise – Sistema Inteligente de Gestión de Riego**

### Descripción

Hydrawise es una plataforma inteligente de control de riego desarrollada por Hunter Industries que permite gestionar sistemas de riego de manera remota mediante conexión Wi-Fi. El sistema utiliza datos meteorológicos en tiempo real para ajustar automáticamente los programas de riego según las condiciones climáticas locales, optimizando el consumo de agua. Además, incorpora monitoreo de caudal, generación de alertas, administración de múltiples sitios y acceso remoto desde dispositivos móviles y computadoras. 

### Aporte al Proyecto

- Sirvió como referencia para implementar el monitoreo y control remoto del sistema de riego.
- Sustentó la importancia de utilizar información ambiental para optimizar el uso del agua.
- Inspiró la incorporación de alertas y supervisión del estado del sistema para detectar posibles fallas.
- Proporcionó criterios de diseño orientados a la automatización y eficiencia hídrica.
- Reforzó la necesidad de una interfaz que permita al usuario consultar información del sistema de forma sencilla.

# Producto 2

### Nombre del Producto

### **Netafim – Soluciones de Riego de Precisión**

### Descripción

Netafim ofrece una amplia gama de tecnologías para riego de precisión, incluyendo válvulas de control, filtros, sistemas de filtración, tuberías, conectores y soluciones de automatización. Sus productos están diseñados para optimizar la distribución del agua, regular la presión, proteger los sistemas hidráulicos y mejorar la eficiencia del riego en aplicaciones agrícolas.

### Aporte al Proyecto

- Sirvió como referencia para el diseño del sistema de distribución de agua.
- Permitió identificar componentes necesarios para el control del caudal y la presión.
- Proporcionó criterios para la selección de elementos hidráulicos aplicables al prototipo.
- Evidenció la importancia de la filtración para evitar obstrucciones en sistemas de riego.
- Ayudó a comprender la integración de válvulas y accesorios en sistemas agrícolas automatizados.

# Producto 3

### Nombre del Producto

### **METER Group ZL6 – Registrador de Datos Inalámbrico**

### Descripción

El ZL6 es un datalogger inalámbrico diseñado para la adquisición, almacenamiento y gestión remota de datos ambientales y agrícolas. Cuenta con conectividad Bluetooth, GPS integrado, almacenamiento en la nube mediante ZENTRA Cloud y capacidad para conectar múltiples sensores de humedad del suelo y variables climáticas. Además, incorpora alimentación mediante energía solar y monitoreo en tiempo real.

### Aporte al Proyecto

- Sirvió como referencia para la gestión y almacenamiento de datos de sensores.
- Sustentó la importancia del monitoreo remoto mediante plataformas digitales.
- Inspiró la integración de sistemas de comunicación para supervisar variables agrícolas.
- Proporcionó criterios para la visualización y análisis de datos en tiempo real.
- Reforzó la necesidad de registrar información histórica para la toma de decisiones.

# Producto 4

### Nombre del Producto

### **Vegetronix VH400 – Sensor de Humedad del Suelo**

### Descripción

El sensor VH400 de Vegetronix permite medir con precisión el contenido volumétrico de agua en el suelo mediante una salida de voltaje proporcional a la humedad detectada. Presenta bajo consumo energético, rápida respuesta, resistencia al agua y una construcción robusta que facilita su uso continuo en aplicaciones agrícolas y sistemas automatizados de riego.

### Aporte al Proyecto

- Sirvió como referencia para la selección y funcionamiento de sensores de humedad del suelo.
- Permitió comprender los principios de medición de la humedad utilizados en sistemas de riego inteligente.
- Proporcionó criterios para la ubicación y operación de sensores en la zona radicular de las plantas.
- Sustentó la importancia de obtener mediciones precisas para automatizar el riego.
- Contribuyó a la definición de las variables de monitoreo empleadas en el proyecto.
